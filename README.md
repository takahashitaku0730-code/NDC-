# NDC実習リマインダー

実習中の手技・予定を時刻つきでメモし、アラーム・通知でリマインドするスマホ向けWebアプリ(PWA)です。

## できること
- 日ごとのタイムライン表示(現在時刻ライン、「次の予定」までのカウントダウン)
- 手技・時刻・所要時間・場所/ベッド・指導医・メモ(持ち物)の登録
- 手技名のワンタップ入力(動脈血採血、ドレーン抜去 など)
- リマインドを 60/30/15/10/5/3分前・開始時刻 から複数選択
- **時間が重なっている予定に ⚠ 表示**
- アラーム時:画面アラーム + 音 + バイブ + 端末通知、5分スヌーズ
- 完了チェック
- その日の予定を `.ics` で書き出し → iPhone/Android のカレンダーに取り込み(カレンダー側の通知でも鳴る)
- 「画面を消さない」モード、オフライン対応

## 使い方
1. GitHub Pages で公開した URL をスマホで開く
2. 共有メニューから「ホーム画面に追加」
3. 「🔔 アラームをテスト」で通知・音を許可して動作確認

## 注意
- ブラウザの制約で、**アプリを完全に閉じている間はアプリ自体のアラームは鳴りません**(iPhoneは特に)。
  確実に鳴らしたい日は「📅 カレンダーに書き出し」でカレンダーにも登録してください。
- データは端末内(localStorage)にのみ保存されます。患者さんの氏名・ID等の個人情報は入力しないでください。

## 公開(GitHub Pages)
リポジトリの Settings → Pages → Source を「GitHub Actions」にし、`main` に マージすると自動で公開されます。
